    Interface ViewingKeyLike

    The ViewingKeyTrait surface. Constructors and secretBytes are excluded on purpose: a backend keeps the secret and exposes only operations over it.

    An implementer must hold viewing-key material in memory. Every operation returns synchronously, as Rust's ViewingKeyTrait does: a backend answering viewing-key operations over a wire is not a supported deployment.
