    Optional ReadonlyallowInsecureHttp

    allowInsecureHttp?: boolean

    Permit plain http to non-loopback indexer and prover URLs.

    Off by default: in plaintext the indexer response reveals which UTXOs an identity owns and the prover request carries the witness, so the transport carries the protocol's privacy. Set this only where the network is already private, and never for a public endpoint.
