## The log split

The log moved from a section of `review-checklist.md` to `planning/typescript-sdk-port/log/`, one file per entry, named `<YYYY-MM-DD>T<HHMM>-<row>.md`. The defect was never that 118 rows shared a file; it was that a mutable table and an append-only log shared one, so an append inherited the table's write races. That is what took the five wallet entries: `23a3ce76` committed the table cells by pathspec while the entries were still unwritten. A new file cannot be carried off in someone else's diff.

Ordering changed with the move and the change is deliberate. The section was read in document order; the directory is read in timestamp order. The two disagree, because workers wrote per-row entries in row order rather than time order, leaving `2026-07-25 00:45` above `2026-07-24 23:49`. A file move must not restate a verdict as a side effect, so [`migrate-from-checklist.mjs`](migrate-from-checklist.mjs) reads the last attributed verdict for every row under both orderings, using the same narrow attribution the check uses, and prints every difference before it writes anything.

Whoever runs it records the result here. This entry was written before the run, because the shell this session was dispatched with stopped returning exit statuses partway through and did not recover; the checklist edits above were made with file tools, and their counts were verified by reading the table rather than by running the check.

After it, each entry is an atomic file addition, which answers the same questions more directly. What is lost is one chronological `git log -p` spanning both sides.
